# YES FAQ Alunos: arquivos de envio

Vídeos e infográfico que o agente "YES Responde" (FAQ de alunos do Ganhando o Mundo, Reino Unido) pode enviar pelo WhatsApp. Os ids (mat-001, 002, 003, 005) batem com `catalogo-materiais-rascunho.csv`.

- `midia/`: 3 vídeos e 1 infográfico. Envio em caráter PROVISÓRIO; a YES confirma.
- `catalogo-materiais-rascunho.csv`: catálogo em rascunho (id, título, tipo, tema, versão, consulta, pode enviar, quando enviar, legenda).

**Fora desta pasta de propósito:** os PDFs oficiais da YES (têm aviso de direitos autorais) e o vídeo antigo de 27/10, que aguarda decisão. Este repositório é público: PDF só entra aqui depois da autorização da YES. Os PDFs estão no repositório privado ddih1997-spec/yes-faq-alunos-arquivos.
